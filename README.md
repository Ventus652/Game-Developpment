# Godot Game Development Portfolio

A collection of progressive 2D and 3D game-development exercises built with Godot 4 and GDScript.

This repository documents my learning path: scene composition, input handling, signals, UI, audio, enemy spawning, scoring systems and 3D gameplay.

## Projects

| Folder | Focus |
| --- | --- |
| `1a` | First Godot scene and GDScript fundamentals |
| `2a` | Area2D interactions and signals |
| `2b` | State-driven interface exercise |
| `2c` | 2D dodge game with score, high score, audio and increasing difficulty |
| `3b` | 2D platformer with animation, collectibles, enemies and kill zones |
| `3c` | Scene-building exercise |
| `3d` | 3D arcade game with movement, procedural enemy spawning, scoring and retry flow |

## Skills demonstrated

- Godot scene and node architecture
- GDScript gameplay programming
- 2D and 3D character controllers
- Signals and event-driven logic
- UI and score systems
- Animation and audio integration
- Difficulty progression and game-state management
- Project organisation and export configuration

## Run a project

1. Install [Godot 4](https://godotengine.org/download/).
2. Open the `project.godot` file inside the project folder you want to explore.
3. Press **F6** to run the current scene or **F5** to run the project.

Example:

~~~text
3d/3d/project.godot
~~~

## Repository structure

Each assignment contains its own Godot project and source files. Generated editor caches and exported binaries are intentionally excluded so the repository stays focused on readable source code.

## Status

This is a learning portfolio. The projects are kept small and focused so each one demonstrates a specific game-development concept.
